# Shared module contract

Importing the `agents` input adds a common environment to every consumer. Keep
these details in this module rather than copying them into each project.

## Tools

The module puts these tools on `PATH`:

- the packaged `project` CLI;
- Git, GitHub CLI, and `just`;
- Claude Code and the pinned `claude-status-line` wrapper;
- Python 3, required by Herdr's Claude integration hook;
- direnv;
- Pi where nixpkgs marks `pi-coding-agent` available for the host platform.

It also appends `~/.local/bin` so native tools such as Herdr remain reachable.
The stable devenv profile stays first on `PATH`, followed by the shared Cargo,
npm, and Bun bin directories.

## Environment and shared state

The module defines:

| Variable                                       | Meaning                                                                         |
| ---------------------------------------------- | ------------------------------------------------------------------------------- |
| `AGENTS_SESSION`                               | Explicit `agents.session`, `.agents/project.toml` session, or checkout basename |
| `AGENTS_PROJECT_ROOT`                          | Canonical main checkout containing the common Git directory                     |
| `AGENTS_PROJECT_STATE`                         | Main checkout's `.devenv/state` directory                                       |
| `AGENTS_WORKTREE`                              | Linked-worktree basename; unset in the main checkout                            |
| `RUSTUP_HOME`                                  | `$AGENTS_PROJECT_STATE/rustup`                                                  |
| `CARGO_HOME`                                   | `$AGENTS_PROJECT_STATE/cargo`                                                   |
| `NPM_CONFIG_PREFIX`                            | `$AGENTS_PROJECT_STATE/npm`                                                     |
| `NPM_CONFIG_CACHE`                             | `$AGENTS_PROJECT_STATE/npm-cache`                                               |
| `BUN_INSTALL`                                  | `$AGENTS_PROJECT_STATE/bun`                                                     |
| `DENO_DIR`                                     | `$AGENTS_PROJECT_STATE/deno`                                                    |
| `DISABLE_AUTOUPDATER`                          | `1`, keeping Nix-managed Claude Code pinned                                     |
| `CLAUDE_CODE_ADDITIONAL_DIRECTORIES_CLAUDE_MD` | `1`, enabling instructions from granted sibling trees                           |

The language state directories are shared by the main checkout and its linked
worktrees. Do not redefine them in a consumer unless the module itself is being
changed.

On Linux, agent configuration is also routed through the host layer:

```text
CLAUDE_CONFIG_DIR=$HOME/.local/share/agents/claude
GH_CONFIG_DIR=$HOME/.local/share/agents/gh
PI_CODING_AGENT_DIR=$HOME/.local/share/agents/pi
```

Darwin leaves those variables undefined so the caller's native configuration
continues to apply.

## Worktree behavior

The module distinguishes the main checkout from a linked worktree using the Git
common directory. Services named by `.agents/project.toml` under
`services.scoped` remain enabled in the main checkout and are force-disabled in
linked worktrees.

Reference service endpoints generated by `project sync` are loaded from:

```text
$AGENTS_PROJECT_STATE/references.env
```

Because this lives in the main checkout's state, every linked worktree sees the
same resolved sibling-service endpoints.

## Tasks and tests

The import adds:

```text
project:gc      -> project gc
project:update  -> project update
```

Its `enterTest` script makes every consumer's `devenv test` assert the shared
contract: project/worktree identity, state directories, PATH ordering, required
tools, and Linux config paths. Consumer-specific `enterTest` content is merged
with these assertions by devenv.
